# Security policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/maxanstey-meridian/cohort/security/advisories/new).

Include what you found, how to reproduce it, and the version affected. You'll get a reply within
a week.

## Supported versions

Only the latest release of Cohort gets security fixes.
